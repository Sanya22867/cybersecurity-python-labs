## 3. Інструкція з розгортання та запуску

### Крок 1. Встановлення залежностей
Виконуйте команди з кореня репозиторію у віртуальному середовищі з Python 3.10+:
pip install -r requirements.txt

### Крок 2. Ініціалізація бази даних та початкове заповнення
Створення файлу бази даних за схемою:
python -m labs.lab03.database

Заповнення бази початковими навчальними даними з seed.json (3 категорії та 8 записів в одній транзакції):
python -m labs.lab03.seed

### Крок 3. Запуск API-сервера
Запуск застосунку в режимі розробки за допомогою Uvicorn:
uvicorn labs.lab03.main:app --reload --host 127.0.0.1 --port 8000

Після запуску інтерактивна документація Swagger UI буде доступна за адресою: http://127.0.0.1:8000/docs

## 4. Приклади основних запитів (cURL)

- Перевірка доступності API:
curl -i "http://127.0.0.1:8000/ping"

- Отримання інформації про студента:
curl -i "http127.0.0.1:8000/student"

- Отримання списку категорій:
curl -i "http://127.0.0.1:8000/categories"

- Отримання списку записів із фільтрацією та пагінацією:
curl -i "http://127.0.0.1:8000/records?category_id=1&status=new&limit=5&offset=0"

- Створення нового запису:
curl -i -X POST "http://127.0.0.1:8000/records" \
  -H "Content-Type: application/json" \
  -d '{"code": "V02-TEST", "title": "Перевірка сервісу 99", "category_id": 1, "value": 7.5, "status": "new"}'
